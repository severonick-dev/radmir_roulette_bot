# Casino Radmir AI — бот-аналитик рулетки

Telegram-бот для игры «Рулетка» в казино на сервере **GTA SA Radmir RP**.
Игроки сообщают выпавшие числа, бот копит статистику по каждому столу и даёт
**честную аналитику** — без обещаний «предсказать случайность».

Бот: [@caz_gospodryad_bot](https://t.me/caz_gospodryad_bot)

## Идея и честная позиция

Рулетка — это генератор случайных чисел. Если он реализован корректно,
**прошлые числа не дают информации о следующем** (это «ошибка игрока»).
Смысл проекта — не «предсказать случайность», а **обнаружить**, есть ли у
конкретного игрового RNG статистически значимое **смещение или паттерн**,
и только при его наличии — использовать.

Поэтому «движок» — не магия, а математика:

- **χ²-тест** на смещение (числа/цвета/дюжины выпадают чаще ожидаемого?);
- **цепь Маркова** — что чаще следует за чем;
- горячие/холодные с доверительным интервалом.

Прогноз выдаём, только когда перекос значим. Иначе честно: «равновероятно».
Нейросеть — поверх накопленных данных, позже.

## Как это работает для игрока

1. `/start` → приветствие и что за бот. Бот **закрытый** — нужен доступ
   (промокод или, позже, оплата).
2. Выбор **сервера** (1 из 21 — скрипты рулетки на них различаются).
3. Выбор казино: **г. Южное** / **г. Лыткарино**.
4. Выбор стола **1–6** (со схемой зала картинкой).
5. Выбор сложности:
   - **Лёгкая** — красное / чёрное;
   - **Средняя** — дюжины (1–12 / 13–24 / 25–36);
   - **Числа** — 0–36.
6. Цикл: бот показывает аналитику по последним спинам → игрок присылает
   выпавшее число → бот сохраняет и обновляет прогноз.

Единица анализа — связка **сервер → казино → стол**. Полная история спинов
хранится без обрезки; для анализа берём последние `ANALYSIS_WINDOW` (≈300)
спинов именно по этой связке, с датами — чтобы учитывать свежесть данных.

## Доступ, промокоды и оплата

Бот закрыт по умолчанию. Доступ = поле `access_until` у пользователя (пока в
будущем `> now()` — доступ есть). Продлевается промокодом, позже — оплатой.

- **Промокоды (нужны сейчас):**
  - `GOSPODRYAD` — месяц бесплатно;
  - `NEKAZUAL` — 1 час бесплатно, **один раз на аккаунт**.
  - Учёт активаций (`promo_redemptions`); лимит на аккаунт и общий лимит.
  - Продление считается от остатка: `access_until = max(now, access_until) + duration`.
- **Админы:** Telegram ID в `ADMIN_IDS` (.env) — всегда есть доступ, гейт их не трогает.
- **Оплата (позже):** ЮKassa (webhook → продлевает `access_until`).

Промокоды засеиваются `seed_promocodes()` (идемпотентно) — подключим на старте бота.

- **SQLAlchemy 2** (async) — БД. Dev: SQLite, прод: Postgres (только `DATABASE_URL`)

## ИИ (RouterAI / DeepSeek)

- Провайдер: **RouterAI** (`https://routerai.ru/api/v1`, OpenAI-совместимый, `Authorization: Bearer`).
- Модель: `deepseek/deepseek-v4-flash` — **reasoning-модель**: часть токенов
  уходит в скрытое рассуждение, поэтому `AI_MAX_TOKENS` держим с запасом (2000),
  иначе `content` придёт пустым.
- Системный промпт **обязателен** (иначе DeepSeek может отвечать не по-русски) и
  задаёт честную позицию: не выдумывать закономерности в случайных данных.
- Роль ИИ: получать посчитанную статистику (χ², Марков, частоты) и превращать её
  в понятный игроку разбор на русском. Сам ИИ не заменяет статистику — комментирует её.

Проверка ключа: `python -m scripts.ai_smoke` (после `pip install -r requirements.txt`).

## Запуск (локально)

```bash
python -m venv .venv && source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env      # вписать BOT_TOKEN и свой ADMIN_IDS
pytest                    # прогнать проверки (37 тестов)
python -m src.bot.main    # запустить бота (long-polling)
```

> Впиши свой Telegram ID в `ADMIN_IDS` (.env) — иначе бот закрыт и для тебя
> (нужен будет промокод). Узнать свой id можно у @userinfobot.

> Для схемы зала нужен шрифт с кириллицей. Локально берётся `arial` (Windows).
> На сервере: `apt-get install -y fonts-dejavu-core` (иначе подписи станут ▯▯).
